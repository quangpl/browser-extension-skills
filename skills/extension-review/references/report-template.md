# Report Template

Default: Markdown at `<extension root>/extension-review-report.md`. Write HTML (`extension-review-report.html`, same content) only when the user asks for it. Overwrite an earlier report from this skill; keep the previous verdict in "Re-scan history" if one existed.

## Verdict rules

Count only **confirmed** findings (false positives go in their own section).
- **WILL BE REJECTED**: any confirmed CRITICAL.
- **NEEDS FIXES**: no CRITICAL, one or more confirmed HIGH.
- **LIKELY APPROVED**: only MEDIUM or nothing. Still list MEDIUM items; reviewers apply discretion.

Never claim approval is guaranteed: the scan covers the code and manifest, not dashboard fields, server behavior at review time, or reviewer discretion.
